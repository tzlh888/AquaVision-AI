# AquaVision AI — Public Release Audit

## Decision

**Conditionally publishable as a LIMITED research record after curation.** The repository already communicates historical limitations well. The new upgrade evidence should be linked, not used to replace or inflate the historical model narrative. After these six closeout documents, the repository has 83 untracked files requiring explicit review.

## README consistency

The README correctly states that CyAN labels are remote-sensing proxies, the historical test is High-enriched, NDCI failed on High despite selection, Logistic Regression cannot be selected post hoc, no CNN passed the guard, and the final modelling conclusion is LIMITED. It also correctly discloses that raw arrays/checkpoints are absent from a lightweight clone and that DeepLab used random initialization.

The README does not yet expose the later recovery and v3 data-engineering outcome. Minimal recommended additions:

1. Add a short “Research upgrade” section linking the final report and one-page summary.
2. State that all 288+288 historical arrays were recovered but 0/288 historical patches gained confirmed real geography.
3. State that the six-product CyAN V6 integration pilot succeeded technically.
4. State that Phase 3A-3 ended with 0 qualified independent High units and 0/0/0 split members; Phase 3B never started.
5. Clarify that the v3 pipeline result is data-integration evidence, not a new model-performance result.

Do not rewrite the entire README or remove historical failures.

## Claims review

The public release may say:

- all historical arrays and memberships were exactly recovered and verified;
- the historical benchmark contains exploratory spectral signal but lacks confirmed real geographic identity;
- six official CyAN V6 products were integrated reproducibly with six Sentinel candidates across three named waterbodies;
- the bounded expansion failed its independent High-unit gate and model training was stopped.

It must not say:

- CyAN classes are toxin measurements, field truth, or direct health-risk labels;
- historical author-grid components are lakes or independent geographic sites;
- 37,768 historical High pixels represent independent High samples;
- the pipeline achieved a classification breakthrough;
- reliable cross-region generalization or deployment readiness has been proved;
- an empty confirmation set was successfully sealed.
