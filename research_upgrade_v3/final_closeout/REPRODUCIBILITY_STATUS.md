# AquaVision AI — Reproducibility Status

## Status

**Historical metrics are artifact-reproducible under their legacy split; the six-scene v3 integration is locally reproducible; geographic model generalization is not reproducible because no qualified independent dataset exists.**

## Reproducible evidence

- 288 historical CyAN arrays and 288 historical Sentinel arrays match frozen hashes.
- Historical v2 membership, label boundaries, component grouping, support counts, and saved model metrics are recorded.
- Six official CyAN V6 source products have exact product IDs, embedded version evidence, dates, grids, encodings, and SHA-256 values.
- Six derived patch-label artifacts trace to specific Sentinel candidates and source products.
- Native-cell identity, nearest-neighbor production labels, bilinear diagnostics, spatial intersection, date matching, and missing-evidence rejection are tested.
- Five Phase 3A-3 candidate identities/geometries and their native CyAN screening are preserved.
- No Phase 3B model or confirmation-set result exists.

## Partial or unavailable reproduction

- Historical v2 real geography, source scenes, footprints, waterbodies, events, and exact CyAN processing version cannot be reconstructed from public artifacts.
- A fresh lightweight clone omits raw arrays, NASA GeoTIFFs, derived `.npz` labels, checkpoints, and caches. Historical full inference requires separately obtained source artifacts.
- Phase 3A-3 did not acquire new Sentinel payloads, so the new-candidate chain stops at identity/geometry/native-label screening.
- No sealed confirmation members exist, so independent confirmation cannot be rerun.

## Data availability and security

Earthdata credentials, cookies, authorization headers, and local authentication files are not stored in the repository or manifests. Raw/derived raster files remain under ignored data paths. Reproduction should download only official products through authorized services and verify manifest hashes; it must not copy a user’s credential files.

## Evidence-strength boundary

Exact reconstruction of an array or label does not establish that it is an independent waterbody observation. Technical reproducibility and statistical independence are separate gates; only the first has been demonstrated for the bounded v3 pilot.
